## General Course Rules & Standards

- **Version Control Cleanliness**: `node_modules/` and local environment files (`.env`) are strictly excluded via `.gitignore`.
- **Security Compliance**: No sensitive credentials, tokens, or plain text secrets are committed.
- **HTTP Integrity**: Every route returns the exact and appropriate HTTP status code (`200 OK`, `404 Not Found`, etc.).
- **Code Quality**: Modular architecture, structured responses, and meaningful commit messages.
